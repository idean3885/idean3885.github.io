# ADR-0008: 카테고리 개요 페이지는 이름과 개수만 보여 준다

## Status

Accepted (2026-11-18)

## Context

카테고리 개요 페이지(`/categories/`)는 커스텀 레이아웃으로 그린다. 이 레이아웃이 한때 하위 없는 단일 카테고리의 글 제목을 개요에 인라인했다.

이어서 상위 카테고리의 직속 글(하위 카테고리 없이 상위에만 속한 글)도 개요에 노출하려 하자, 개요에 글 제목이 쏟아져 카테고리 구조가 보이지 않게 됐다.

Chirpy 기본 동작과 일반 블로그 관례는 개요를 디렉터리로 쓰고, 글 목록은 개별 카테고리 페이지에 맡긴다. #349 에서 레이아웃을 이 관례로 되돌렸고, 지금 레이아웃은 그대로 동작한다. 다만 규칙 문서에 적혀 있지 않아, 레이아웃을 고칠 때 같은 회귀가 다시 생길 수 있다.

## Decision

1. **개요 페이지는 카테고리 이름과 개수(폴더)만 노출한다.** 개별 글 제목은 노출하지 않는다.
2. **글 목록은 개별 카테고리 페이지(`/categories/{name}/`)가 맡는다.** 상위 카테고리 페이지는 직속 글과 하위 카테고리 글을 모두 보여 준다.
3. **하위 없는 단일 카테고리는 개요에서 펼치지 않는다.** 이름을 눌러 카테고리 페이지로 이동한다.
4. **커스텀 요소는 상단 「전체 N개 카테고리, M편」 요약 카드만 둔다.**

## Consequences

- 개요가 카테고리 수에 비례해 짧게 유지되고, 카테고리 구조가 한눈에 보인다.
- 글에 도달하려면 한 번 더 누른다. 글 탐색은 카테고리 페이지 · 전체 포스트 목록 · 검색이 맡는다.
- 레이아웃을 고칠 때 이 결정이 기준이 된다. 개요에 글을 다시 넣으려면 이 ADR 을 대체한다.

## Alternatives

| 대안 | 기각 사유 |
|---|---|
| 단일 카테고리 글만 개요에 인라인 | 상위 직속 글과 기준이 갈려, 직속 글을 넣으려는 순간 개요가 다시 길어진다 |
| 모든 카테고리 글을 개요에 펼침 | 글 수에 비례해 개요가 길어져 구조가 묻힌다. 카테고리 페이지와 역할이 겹친다 |
