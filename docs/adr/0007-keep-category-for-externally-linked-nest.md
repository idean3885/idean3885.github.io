# ADR-0007: 외부에서 고정 링크된 카테고리는 1편이어도 유지한다

## Status

Accepted (2026-09-20)

## Context

ADR-0004 는 하위 카테고리를 2편 이상 모인 둥지에만 부여하고, 1편짜리 주제는 상위 카테고리만 쓰도록 정했다. 라벨만 있고 내용이 없는 카테고리가 사이드바를 채우는 것을 막기 위해서다.

「미터링 시스템 구축」 하위 카테고리에는 3편이 있었다. 세 글이 같은 시스템을 다루면서 규모 수치와 설계 서술이 서로 어긋나, 한 편으로 통합했다(#395). 통합 결과 이 카테고리는 1편이 되어 ADR-0004 기준 밖으로 나간다.

그런데 이 카테고리 페이지는 **외부 문서가 직접 링크하고 있다.** 그 문서는 이미 배포돼 수정할 수 없다. 카테고리를 제거하면 소속 글이 0편이 되고, Chirpy 가 해당 페이지를 생성하지 않아 링크가 404 가 된다.

ADR-0004 가 막으려던 것은 **내용 없는 라벨**이다. 이 경우는 내용이 없어서 1편인 것이 아니라, 있던 것을 합쳐서 1편이 된 것이다. 카테고리 페이지를 열면 통합 글 한 편이 있고 그 글이 카테고리 주제를 전부 담는다.

선례도 있다. Kubernetes 하위 카테고리는 1편이지만 ADR-0002 가 학습 글 누적을 의도해 신설한 선행 라벨이라 유지 중이다. 1편 하위 카테고리 자체는 이미 예외로 운영되고 있다.

## Decision

1. **외부에서 고정 링크된 카테고리 페이지는 소속 글이 1편이 되어도 유지한다.** ADR-0004 의 예외다.
2. **예외 사유는 링크 출처를 명시해 기록한다.** 「어딘가 링크가 있다」로는 부족하고, 어느 문서가 왜 수정 불가인지를 적는다.
3. **이 예외는 카테고리를 새로 만드는 근거가 되지 않는다.** 이미 있는 카테고리를 유지하는 근거로만 쓴다.

## Consequences

- 통합으로 카테고리 글 수가 줄어도 외부 링크가 살아 있다.
- ADR-0004 의 기준은 그대로 유지된다. 신규 하위 카테고리는 여전히 2편 이상일 때만 만든다.
- 1편 하위 카테고리가 Kubernetes 에 이어 둘이 된다. 셋째가 나오면 ADR-0004 기준 자체를 재검토한다.

## Alternatives

| 대안 | 기각 사유 |
|---|---|
| 카테고리를 제거하고 상위만 남긴다 | 외부 고정 링크가 404 가 된다. 그 문서는 수정할 수 없다 |
| 통합하지 않고 3편을 유지한다 | 세 글의 수치·설계 서술이 어긋난 상태가 남는다. ADR-0003(1편 단독 완성형)에도 어긋난다 |
| 카테고리 페이지만 남기는 더미 글을 둔다 | ADR-0004 가 막으려던 「내용 없는 라벨」 그 자체다 |
